# Kadık — Proje Özeti

## Hedef
Kadık için Türkçe, kampanya/örgütlenme odaklı kurumsal public site: referans Partiso sayfalarının görsel ritmini ve etkileşimlerini korurken içerik, form ve yönetim altyapısını Metro starter üzerinde sürdürmek.

## Public kapsam
`/`, `/hakkimizda`, `/etkinlikler`, `/gonulluluk`, `/duyurular`, `/yazilar`, yazı detayı, `/iletisim`, `/galeri`, `/gizlilik-politikasi`, `/kullanim-sartlari`.

## Başarı ölçütü
1440×900 ve 390×844 capture ölçülerinde ortak header/banner/footer, mobil menü, yazı filtresi, galeri lightbox, form API ve Hono health endpoint çalışır. DB kalıcılığı PostgreSQL bağlantısı hazır olduğunda doğrulanır.
