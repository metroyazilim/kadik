# Admin Sözleşmesi

Mevcut `/manage` shell, auth, medya, posts, pages, messages, site-settings ve SEO menüleri korunur. Kadık public alanları için sonraki dikey slice'ta Events, Issues ve Gallery entity/editor route'ları eklenmelidir. Bu ilk kurulumda mevcut admin'in public sayfa projeksiyonunu bozacak paralel bir yönetim paneli oluşturulmadı.
