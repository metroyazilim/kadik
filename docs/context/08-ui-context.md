# UI Context

Token'lar `app/globals.css` içindeki `--kadik-*` değişkenleridir: navy `#191c39`, ink `#1a273d`, red `#ed2632`, blue `#5b87e8`, hairline `#e5e5e8`. Public shell serif başlık + sans gövde, geniş whitespace, 3 kolon kartlar, lacivert CTA bandı ve mobil tek kolon kurallarıyla çalışır.

İkonlar için metin/Unicode yalnız sosyal küçük rozetlerde kullanıldı; ana tasarımda sahte ikon fontu kullanılmadı.
